# @react-webmcp-kit/core

React hooks and provider for WebMCP tool registration (`McpProvider`, `useMcpTool`, `McpDevTools`).

## Install

```bash
pnpm add @react-webmcp-kit/core use-webmcp-tool zod
```

See the [monorepo README](https://github.com/stubbies/webmcp-kit-react#readme) for usage and demos.
