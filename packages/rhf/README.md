# @react-webmcp-kit/react-hook-form

React Hook Form adapters for WebMCP (`McpFormTools`, `useMcpSubmitTool`).

## Install

```bash
pnpm add @react-webmcp-kit/react-hook-form @react-webmcp-kit/core react-hook-form use-webmcp-tool zod
```

See the [monorepo README](https://github.com/stubbies/webmcp-kit-react#readme) for usage and demos.
