# @react-webmcp-kit/zustand

Zustand store action adapters for WebMCP (`McpStoreTools`).

## Install

```bash
pnpm add @react-webmcp-kit/zustand @react-webmcp-kit/core zustand use-webmcp-tool zod
```

See the [monorepo README](https://github.com/stubbies/webmcp-kit-react#readme) for usage and demos.
